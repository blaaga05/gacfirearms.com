IMPORTANT CONTACT-FORM NOTE
The contact form uses a mailto link. It opens the visitor's email application with the correct address, subject, and message filled in. It does not send silently from the webpage. A hosted form service can be added later.

FREE PUBLISHING OPTIONS
1. Cloudflare Pages — recommended
2. GitHub Pages
3. Netlify

CLOUDFLARE PAGES QUICK START
1. Create a free Cloudflare account.
2. Open Workers & Pages.
3. Choose Create application, then Pages, then Upload assets.
4. Upload the contents of this folder, or drag in this folder as a project.
5. After deployment, add gacfirearms.com as a custom domain.
6. Follow Cloudflare's DNS instructions.
7. Do not delete the existing Google Workspace MX records used for email.
